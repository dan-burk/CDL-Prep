# CDL Prep logo prompts (Gemini)

## 1. Logo mark (primary)
Use for the app header, social previews, and as the source for everything else.

```
Flat vector icon of a semi truck (Class A tractor-trailer) in side profile, facing right. Built from simple geometric shapes: rectangular trailer, boxy cab, round wheels. Bold, solid silhouette in royal blue #2554FF with dark ink #1C1E26 for wheels and windows. Clean, minimal, modern app-icon style. Thick shapes, few details, clearly readable at 32px. Centered on a plain pure white background with generous padding. Square 1:1. No text, no gradients, no shadows, no 3D, no outlines of the ground or road.
```

## 2. Favicon variant
Use for the browser tab icon and home-screen icon (16–32px).

```
Ultra-simple flat icon of a semi truck cab in side profile, facing right, solid white on a rounded-square tile filled with royal blue #2554FF. Only the essential shape: cab, window cutout, two round wheels. Very thick shapes, almost no detail, high contrast, designed to read clearly at 16px. Truck centered and filling about 70% of the tile. Square 1:1. No text, no gradients, no shadows, no 3D, no outlines.
```

## 3. Logo with wordmark
Use for wide spots like a page header or README banner.

```
Horizontal logo: on the left, a flat vector side-profile semi truck (tractor-trailer) icon in royal blue #2554FF with ink #1C1E26 wheels, simple geometric shapes, bold silhouette. To its right, the text "CDL Prep" in a plain bold sans-serif font, color #1C1E26, vertically centered with the truck. Clean, flat, minimal. Plain pure white background. Wide 3:1 layout. No other text, no tagline, no gradients, no shadows, no 3D.
```

Image generators often misspell text. If "CDL Prep" comes out wrong, generate the mark alone (prompt 1) and add the text in code with the system sans-serif font.

## Tips
- Ask for a 1024×1024 PNG (append "Output a 1024×1024 PNG.").
- Regenerate 3–4 times and pick the cleanest, simplest result.
- If extras creep in, add: `Avoid: photorealism, gradients, shadows, 3D, extra text, watermarks, busy background.`
- SVG is best for the site: trace the chosen PNG to SVG with Inkscape (Path > Trace Bitmap) or a vectorizer tool.
- Make favicons by exporting at 512, 192, 180 (apple-touch-icon), 32, and 16, or upload the image to realfavicongenerator.net.
- Check the favicon at actual 16px in a browser tab before settling on it.
